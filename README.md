# Studio Lab

Static site (GitHub Pages) hosting the **Miami Peculiar storefront**, built with [Eleventy](https://www.11ty.dev/).

## Develop

```
npm install
npm run dev       # http://localhost:8080
npm run build     # -> _site/
npm run verify    # build + invariant checks (tools/verify_site.py)
```

## Structure

```
src/                       ← edit here
  apps/storefront/         Page templates (.njk) + front matter
    index.njk (hub)  gorras.njk  magnets.njk  stickers.njk
    colecciones/{miami,cuban-american,miami-beach}.njk
  _data/                   Content + config
    site.json              Brand, contact, base URL (injected into every page)
    magnets.json           Magnets — also drives the 3 collection pages
    gorras.json            Caps + colourways
    stickers.json          Stickers, grouped into sections
  _includes/               Shared layout, partials, card macros, per-page CSS
  _vendor/hub.html         Pre-built React hub — never edited, never parsed;
                           index.njk injects the shared masthead into it

assets/                    Shared runtime + images: order.js, cart.js, flip.js,
                           hub-nav.js, brand.css, masthead.css, img/
index.html                 Root → the "Catálogo 2026" app (hand-authored, not templated)
_site/                     Build output (gitignored — never commit)
```

## Deploy

Push to `main` → GitHub Actions builds with Eleventy and publishes `_site/` (`.github/workflows/static.yml`). The invariant checks run against the built output, so a bad build never ships. `deprecated/` and `src/` are never copied into `_site/`. Root `/` serves the Catálogo 2026 app; the storefront lives at `/apps/storefront/`.

Work on a branch and open a PR — merging to `main` publishes.

## ⚠️ Frozen source

Pages were originally generated by an AI site builder but are now **maintained by hand as the source of truth**. Do **not** overwrite a page with a fresh export — it wipes SEO tags, order-form wiring, and other production changes. Edit `src/` for the six storefront pages; edit the hub surgically. Roadmap + decisions: [docs/REMEDIATION-PLAN.md](docs/REMEDIATION-PLAN.md). Working conventions: [CLAUDE.md](CLAUDE.md).
